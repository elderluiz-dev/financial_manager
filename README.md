# Financial Manager

Repositório de estudos em Python para praticar e aplicar conceitos de programação em um projeto simples de gerenciamento financeiro.

## Objetivo
Explorar e aplicar conceitos como:
- variáveis e tipos de dados
- estruturas de controle
- funções
- listas e dicionários
- leitura/escrita de arquivos
- organização de código
- lógica de negócio básica

## Estrutura
O projeto está em desenvolvimento e tem como foco aplicar esses conceitos em um contexto realista de controle financeiro.

## Como executar
1. Clone o repositório:
```bash
git clone https://github.com/elderluiz-dev/financial_manager.git
```

2. Acesse a pasta:
```bash
cd financial_manager
```

3. Execute o programa:
```bash
python main.py
```

## Observação
Este repositório foi criado como espaço de estudo e prática. A ideia é aprender fazendo, aplicando conceitos de Python em um projeto simples e funcional.
